# Retired legacy image-refresh runbook

> Historical implementation/qualification record. Image/profile, Bridge,
> provisioning, pins and service names below describe the dated experiment,
> not current deployment or installation. Start with [RESUME](../../RESUME.md)
> and the [current architecture index](https://github.com/AlterMundi/daimon-matrix/blob/main/docs/current-architecture.md).
> Preserve this evidence; do not recreate Bridge or bilateral Tribe defaults.
> Past maintenance consent never authorizes a new global Stop or host restart.

The former runbook built and rolled a `tribe-base` image containing Tribe
Bridge. It is intentionally non-executable after issue #102: its builder,
pins, image manifest, profile name and fallback assumptions were removed.

Do not adapt an old copy for V0.1.0. A stable embodiment is created through
the root-authorized Matrix/Cluster birth or rebirth path, from exact offline
artifacts and fresh custody. Host installation and rollback require the
reviewed content-addressed stable preflight and its exact GO.

The deleted procedure remains recoverable from Git history solely as evidence
of the experiment. It is not a supported compatibility or downgrade path.
